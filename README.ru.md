# Jakapil-cli (Якапиль). Неофициальный CLI для сервисов Селектел.

![Yakapil](assets/images/yakapil_nature.jpeg)

## Кто такой Якапиль

**Якапиль** (или, если быть точным, _«якапиль канюкура»_) — динозавр, останки которого обнаружили относительно недавно, в 2022 году в Аргентине.
Это небольшой растительноядный динозавр, который жил около 100 миллионов лет назад.
В длину он был примерно 1,5 метра (включая хвост), а весил всего 4–7 кг, то есть размером и весом он был примерно с домашнюю кошку.
Несмотря на скромные габариты, это был бронированный динозавр: вдоль шеи, спины и хвоста у него шли ряды костяных щитков и шипов, а передвигался он на двух задних ногах.
По образу жизни он был скорее «осторожным вегетарианцем», который полагался на защитную броню и, возможно, на скорость, так что из современных питомцев его можно сравнить не столько с кошкой, сколько с небольшой собакой.

Якапиль, конечно, не такой популярный, как трицератопс или тиранозавр Рекс, но полезный и классный!

А если серьезно...

**jakapil-cli** — попытка создать «всеобщий» CLI на Go для сервисов Селектел. Вдохновляется инструментами других провайдеров и CLI OpenStack. Предполагается использование только существующих Go SDK Селектела. Функциональность будет добавляться постепенно.
В данный момент из специфичных сервисов поддерживаются Managed Kubernetes (MKS) и Container Registry.

Конечная цель — все сервисы провайдера Selectel.

По IaaS присутствует поддержка:

- управления жизненным циклом ВМ и связанных сущностей (образов, томов, флейворов, SSH-ключей)
- управления жизненным циклом сетевых сущностей (сетей, подсетей, портов, роутеров, «плавающих» адресов)

Еще **не реализовано**, но в ближайших планах:

- публичные подсети
- прямые публичные адреса
- DNS-хостинг
- приватный DNS-сервис
- балансировщики нагрузки
- группы безопасности
- базовый облачный файервол
- выделенные серверы

Остальное будет фиксироваться в роадмапе.

## Как собрать Якапиля

Все достаточно тривиально:

```
git clone https://github.com/kot1grun/jakapil-cli
mkdir -p bin/
go build -o bin/ .
```

Но удобнее пользоваться Makefile-ом. Конечно, у вас должен быть установлен GNU Make.

```
make build
```

## Быстрый старт

Перед тем как начать использовать утилиту, следует:

- Создать аккаунт в Селектел (если его нет). Страница регистрации [находится здесь](https://my.selectel.ru/registration).
- Создать проект (если его нет) или использовать проект по умолчанию. Список проектов находится в [панели управления](https://my.selectel.ru/iam/projects).
- Создать [сервисного пользователя](https://docs.selectel.ru/access-control/user-types/#service-users) с правами [member](https://docs.selectel.ru/access-control/role-reference/#member) выбранного проекта и всех тех проектов, ресурсами которых предполагается управлять.
  Либо можно использовать member с областью действия на весь аккаунт.

После выполнения всех предварительных требований:

1. Собираем или устанавливаем jakapil-cli.
2. Скачиваем сформированный rc-файл для сервисного пользователя.
3. Импортируем rc-файл.

```

source rc.sh

```

Скрипт запросит ввод пароля сервисного пользователя.

4. Выписываем себе токен для аутентификации в API.

```

jakapil-cli authenticate token issue --account-scope --project-scope --ask-pass

```

Утилита запросит пароль сервисного пользователя и в случае, если пароль верный, выдаст и сохранит в файл токены с областью действия «проект» и «аккаунт».

5. Можно пользоваться Якапилом! Например:

```

jakapil-cli mks cluster list --region ru-6

```

выведет список кластеров Kubernetes в облачном пуле ru-6.

## Приятные возможности Якапиля

Помимо очевидного факта, что jakapil-cli написан на Go и все статически скомпилировано в одном файле, стоит отметить:

- вывод в трех форматах: человекочитаемый табличный, YAML и JSON
- флаг _--all-regions_ в листингах, который отобразит инстансы сервиса (будь то ВМ, сеть или кластер Kubernetes) во всех доступных регионах
- возможность создавать highfreq-флейворы для ВМ
- прогрессбар при скачивании/загрузке образов с указанием оставшегося и прошедшего времени и скоростью

## Особенности (или, если удобнее, «неприятные моменты») Якапиля

- утилита (пока) не знает имен и работает только с UUID сервисов
